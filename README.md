# T3 Code Unbound

[T3 Code](https://github.com/pingdotgg/t3code) with file attachments of any size.

This repository holds a small patch series and a workflow. The workflow watches
upstream for stable releases, applies the patches to each one, and publishes the
runtime archives that `t3 update` installs. T3 Code itself is not vendored here.
